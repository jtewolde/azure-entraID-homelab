# 04 - Sign In Log Investigation

## Overview

Monitoring user sign-in activity is an important responsibility of an Identity and Access Administrator. Microsoft Entra ID provides sign-in logs that allow administrators to review authentication activity, investigate failed sign-ins, and troubleshoot user access issues.

In this section of the Microsoft Entra ID homelab, I practiced investigating user authentication activity using the Microsoft Entra Admin Center.

The purpose of this lab was to explore sign-in logs, identify successful and failed authentication attempts, review sign-in details, and understand how administrators can use this information to troubleshoot account access issues.

---

## Objectives

The objectives of this lab are to:

- Understand the purpose of Microsoft Entra sign-in logs.
- Locate and navigate sign-in activity within the Entra admin center.
- Identify successful and failed sign-in attempts.
- Filter sign-in logs by user and authentication status.
- Investigate authentication failures and their associated error information.
- Review authentication, device, and location details.
- Export sign-in logs for further investigation.
- Understand how sign-in logs support identity troubleshooting and security monitoring.
